# SCAFFOLD - what goes where

The directory skeleton described in `initial_v0/00_project_walkthrough.md` section 2, and what
belongs in each place. Most of it is now populated; this file records the intent so future
additions land in the right spot.

## Layout and contents

| path | contents | milestone |
|---|---|---|
| `config/` | reserved for moving the policy constants in `src/utils/config.py` out to YAML. Currently empty (a `.gitkeep` keeps it visible) | later |
| `data/raw/` | reserved as the formal home of the raw extract. **The three raw CSVs still sit at the repository root**, because `src/utils/config.py` resolves them there (`RAW_DIR = PROJECT_ROOT`); moving them means changing `RAW_DIR` in the same commit | later |
| `data/interim/` | postcode lookup tables, the event specification, the geocoded distance distribution | W1-W2 |
| `data/processed/` | `clean.parquet`, `features.parquet`, `panel_postcode_month.parquet` | W1-W3 |
| `data/external/` | `events.csv`, the two RBA snapshots (cash rate, CPI) | W2, W5 |
| `src/data/` | `io.py` (chunked reading, postcode keys), `contract.py` (assertions), `clean.py` (the 16 steps), `postcode_features.py` (labels, distances, join), `outliers.py` (three-layer fences), `macro_asof.py` (monthly macro), `events.py` (event table, treatment), `geocode_features.py` (property-level distances) | W1-W3 |

| `initial_v0/` | design documents and audits | - |
| `attic/` | unused files, gitignored; see `attic/README.md` | - |

## Three rules that hold everywhere

1. **No logic in notebooks.** Notebooks import from `src`, driven by `pipelines/`. The original
   notebook's problem was logic, data, conclusions and figures in one file.
2. **`pipelines/` is the only entry point.** Each script is independently runnable and idempotent.
3. **`reports/` is the only output.** Every number traces to a CSV in `reports/tables/`, and every
   figure is regenerated by `07_make_report.py`, so text and images cannot drift apart.
